A one-star review written by a house cat about its human, built for the [Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990) bounty on make.fun. It writes a single deadpan review line to `/output/entry.txt` — the cat's 3am yowling outside the locked bathroom door, reframed as the cat conducting its own performance review of its human.

The review (168 characters, one line):

> One star. He shuts the bathroom door like I have never watched him use it, so I sing outside until he opens it. He calls it 3am. I call it my performance review of him.

`main.ts` validates the line against the bounty gate (1–200 characters, single line, not only whitespace) before writing it.

## Run

```sh
node main.ts
```
